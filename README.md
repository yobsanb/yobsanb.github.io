## Manage my portfolio

[Owner login — open Portfolio Studio](https://studio.yobsanb.workers.dev/login)

Sign in with the owner GitHub account, `yobsanb`. This README is the entry point for editing; public website pages have no login links or editor redirect. The Studio is hosted separately and still requires owner authentication.

To change the website profile picture, open **Profile & links → Change profile photo**, choose a JPEG, PNG, or WebP image (up to 10 MB), and check the preview. Click **Save & preview**, then **Publish to GitHub → Publish now** to make it public. This changes the portfolio portrait; your GitHub account avatar is managed separately in GitHub settings.

News, publications, projects, biography, and research directions can be edited in the same Studio. Saves stay private until published.
